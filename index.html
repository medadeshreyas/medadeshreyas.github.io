About

I've built the kind of things nobody thinks about — until they break.

That's mostly what the last four years have been about: building and hardening platforms — across banking, fintech, and transit — where downtime isn't an inconvenience, it's a headline.

Most of that work sits in the backend — Java microservices, HSM-based key security, encryption across banking integrations, and APIs that hold up under real transaction load. But I've never treated frontend as someone else's problem; I've built and maintained React interfaces for the same systems, because ownership doesn't stop at the API boundary.

What I've learned to value most isn't the clever solution, it's the boring, reliable one — the kind that survives a production incident at 2am, the kind a junior engineer can pick up without me explaining it twice. That's shaped how I mentor too: I've sat on 70+ technical interviews, less to gatekeep and more to find people who think the same way.
